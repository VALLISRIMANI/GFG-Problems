<h2><a href="https://www.geeksforgeeks.org/problems/split-singly-linked-list-alternatingly/1">Split Linked List Alternatingly</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given the head of a singly linked list, split the list into two sub-linked lists by placing alternating nodes into each list. </span></p>
<ul>
<li><span style="font-size: 14pt;">The first node should go to the first list, the second node to the second list, the third node to the first list, and so on. </span></li>
<li><span style="font-size: 14pt;">Preserve the relative order of nodes in both sub-linked lists and return them as an array of two linked lists.</span></li>
</ul>
