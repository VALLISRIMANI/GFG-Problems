We need to find an initial arrangement of these cards such that the following process removes the cards in the order 1, 2, 3, …, n.</span></p><p><span style="font-size: 14pt;">Do the following for every number k from 1 to n:</span></p><ul><li><span style="font-size: 14pt;">Move the first k cards of the deck to the back of the deck, one by one.</span></li><li><span style="font-size: 14pt;">After these k moves, pick the card at the front.</span></li><li><span style="font-size: 14pt;">This card must be equal to k.&nbsp; If it is, remove it from the deck and continue. If it is not, then no valid arrangement exists.</span></li></ul><p><span style="font-size: 14pt;">If such an arrangement of decks is possible, output the arrangement, if it is not possible for a particular value of n then output -1.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input</strong>: n = 4
<strong>Output: </strong>[2, 1, 4, 3]
<strong>Explanation</strong>:
We initially have [2, 1, 4, 3]
Step1, we move the first card to the end. Deck now is: [1, 4, 3, 2]
Step2, we get 1. Hence we remove it. Deck now is: [4, 3, 2]
Step3, we move the 2 front cards one by one to the end  ([4, 3, 2] -&gt; [3, 2, 4] -&gt; [2, 4, 3]) Deck now is: [2, 4, 3].
Step4, we get 2. Hence we remove it. Deck now is: [4, 3]
Step5, we move the first 3 cards, </span><span style="font-size: 14pt;">[4, 3] -&gt; [3, 4] -&gt; [4, 3] -&gt; [3, 4]. Deck now is: [3, 4] <br></span><span style="font-size: 14pt;">Step6, we get 3. Hence we remove it.
